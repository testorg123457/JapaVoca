> **목적**: 정보구조(IA)를 다시 짜기 전에 **지금 뭐가 어디 있는지** 사실 그대로 적어 둔다.
> 이 문서는 재설계안이 아니라 **재료**다. 개선안은 여기서 합의한 뒤 별도로 만든다.

## 1. 전체 지도

하단 탭은 없다(제거됨). **홈 단일 스크롤 + 스택 push** 구조다.

```
Home ─┬─ [헤더 좌] 캐시 잔액 ──────────────→ Ledger (캐시 내역)
      ├─ [헤더 우] 알림 종 ────────────────→ Notifications
      ├─ [헤더 우] 설정 ──────────────────→ Settings ─┐
      ├─ 퀴즈 CTA 카드 ───────────────────→ LockQuiz  │
      ├─ 상자 카드 ──────────────────────→ BoxOpen   │
      ├─ 리스트 ┬ 히라가나 / 가타카나 ─────→ Kana      │
      │         ├ 기프티콘 교환 ───────────→ Exchange  │
      │         ├ 일본어 번역 ────────────→ JapaneseTranslate → TranslateCrop → TranslateResult
      │         └ 북마크 ────────────────→ Bookmarks │
      └─ 배너 ┬ 친구 초대하고 캐시 받기 ────→ AccountSettings ←┐
              ├ 사진 찍어 일본어 번역 ──────→ JapaneseTranslate│
              └ 캐시로 기프티콘 교환 ───────→ Exchange         │
                                                              │
Settings ─┬─ 프로필 블록 (표시 전용, 이동 없음)                 │
          ├─ 학습 트랙 (인라인 편집 + 저장 버튼)                │
          ├─ 캐시·내역 ┬ 캐시 내역 ─────────→ Ledger           │
          │            └ 기프티콘 보관함 ───→ GifticonWallet → GifticonDetail
          ├─ 소리 ── 정답·오답 효과음 (토글)                    │
          ├─ 알림 ┬ 알림 보기 ──────────────→ Notifications    │
          │       ├ 푸시 알림 (토글)                            │
          │       ├ 학습 리마인더 (토글)                        │
          │       └ 마케팅·이벤트 알림 (토글)                   │
          ├─ 계정 ┬ 계정 설정 ─────────────→ AccountSettings ──┘
          │       └ 잠금화면 설정 ──────────→ LockSettings ─┐
          ├─ 지원 ── 문의하기 ──────────────→ Inquiry       │
          └─ 버전 텍스트 (v0.0.1)                            │
                                                             │
AccountSettings ─┬─ 친구 초대 블록 ──────────→ ReferralRedeem │
                 ├─ 화면 표시 ── 테마 모드 (시스템/라이트/다크)│
                 ├─ 계정 연결 ┬ 구글로 연결   ※ 게스트만 노출  │
                 │            └ 카카오로 연결                  │
                 ├─ 약관·정책 ┬ 이용약관 ─────→ TermsDetail    │
                 │            └ 개인정보처리방침 → TermsDetail  │

LockSettings ─┬─ 잠금화면 학습 ── 화면 켤 때 퀴즈 띄우기 (토글) ┘
              └─ 꾸미기 ── 잠금화면 디자인 ──→ LockTheme (테마 11종 + 내 사진)
```

## 4. 설정 안의 설정 (2단계)

### 4-1. 계정 설정 (`AccountSettings`) — 홈 기준 **3단계**

| # | 섹션 | 항목 | 종류 | 비고 |
|---|---|---|---|---|
| 1 | (최상단) | 친구 초대 블록 — 내 코드 + 공유 | 표시 + 이동 | 코드 입력은 `ReferralRedeem` |
| 2 | 화면 표시 | 테마 모드 (시스템 / 라이트 / 다크) | 세그먼트 | |
| 3 | 계정 연결 | 구글로 연결 | 액션 | **게스트일 때만 노출** |
| 4 | 계정 연결 | 카카오로 연결 | 액션 | **게스트일 때만 노출** |
| 5 | 약관 · 정책 | 이용약관 | 이동 | `TermsDetail{kind:'terms'}` |
| 6 | 약관 · 정책 | 개인정보처리방침 | 이동 | `TermsDetail{kind:'privacy'}` |
| 7 | (무제목) | 회원 탈퇴 | 위험 액션 | 확인 시트 |

### 4-2. 잠금화면 설정 (`LockSettings`) — 홈 기준 **3단계**

| # | 섹션 | 항목 | 종류 | 비고 |
|---|---|---|---|---|
| 1 | 잠금화면 학습 | 화면 켤 때 퀴즈 띄우기 | 토글 | 네이티브 모듈 |
| 2 | 꾸미기 | 잠금화면 디자인 | 이동 | `LockTheme` — 홈 기준 **4단계** |

기기가 지원하지 않으면 두 섹션 다 숨기고 안내 문구만 뜬다.

### 4-3. 잠금화면 디자인 (`LockTheme`) — 홈 기준 **4단계**

퀴즈 테마 11종(classic·olive·dracula·sage·editorial·fintech·chrome·purple·luxury·mint·custom) 선택.
`custom`은 갤러리에서 사진을 고른다.

## 6. 지금 눈에 띄는 문제

조사하면서 나온 것들. **판단이 아니라 관찰**이고, 개선안은 따로 잡는다.

### A. 분류가 이름과 안 맞는다
1. **"계정" 섹션에 잠금화면 설정이 들어있다.** 계정과 아무 상관이 없다.
2. **테마(라이트/다크)가 계정 설정 안에 있다.** 계정이 아니라 앱 표시 설정인데 3단계 깊이에 묻혀 있다.
3. **친구 초대가 계정 설정 최상단에 있다.** 캐시가 걸린 리워드 기능인데 "캐시 · 내역"이 아니라 계정 안이다.
   홈 배너("친구 초대하고 캐시 받기")도 `ReferralRedeem`이 아니라 **계정 설정 화면 전체**로 보낸다 —
   캐시를 약속하고 설정 페이지에 떨궈 놓는 셈.

### B. 같은 것이 여러 군데로 갈라진다
4. **알림이 두 곳.** 홈 헤더 종 → `Notifications`, 설정 > 알림 > "알림 보기" → 같은 화면.
   게다가 설정의 "알림" 섹션 안에 **보기(이동)와 설정(토글)이 섞여** 있다.
5. **기프티콘이 두 곳.** 교환은 홈 리스트, 보관함은 설정 > 캐시·내역. 한 흐름인데 정반대 위치다.
6. **캐시 내역 진입점 2개.** 홈 헤더 잔액, 설정 > 캐시·내역. (중복이지만 홈 쪽은 자연스러운 편)
7. **배너 3장 중 2장이 바로 위 리스트와 중복.** "일본어 번역"·"기프티콘 교환"이 리스트에도 배너에도 있다.

### C. 성격이 다른 게 한 그룹에 있다
8. **홈 리스트 4개가 제각각.** 학습(가나·북마크) / 리워드(기프티콘 교환) / 도구(번역)가 한 묶음이다.
9. **설정의 학습 트랙만 인라인 편집 블록.** 나머지는 전부 한 줄짜리 행인데 여기만 큰 편집 UI라 리듬이 깨진다.

### D. 죽은 길
10. **`StyleGuide` · `GestureDebug`는 진입점이 없다.** `__DEV__`로 스택엔 등록돼 있지만
    **어떤 화면에서도 navigate하지 않는다.** (진입점이 없는 게 맞다 — "설정 → 디자인 시스템"이라던
    `프로잭트-현황.md`의 **틀린 문구는 2026-08-04에 지웠다.**)
11. **`WalletScreen`은 `MainStack`에 등록조차 안 돼 있다.** 코드만 남은 잔재(`BottomTabParamList`도 함께).

### 문제가 아닌 것 (확인됨)
- **로그아웃 없음은 의도된 설계다.** 계정 전환 수단은 회원 탈퇴뿐. (2026-08-04 확인)
  `SettingsScreen`에 있던 "로그아웃은 계정 설정 화면에 있음"이라는 **틀린 주석은 지웠다.**
