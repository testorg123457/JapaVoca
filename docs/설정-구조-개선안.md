## 1. 진단 — 왜 어지러운가

항목이 많아서가 아니라 **묶는 축이 없어서**다. 지금 설정 첫 화면에는 성격이 다른 네 가지가 나란히 있다.

| 성격 | 지금 있는 것 |
|---|---|
| 바꾸는 것 (진짜 설정) | 학습 트랙, 효과음, 푸시 3종 |
| 보는 것 (기능) | 캐시 내역, 기프티콘 보관함, 알림 보기 |
| 다른 설정으로 가는 문 | 계정 설정, 잠금화면 설정 |
| 그 외 | 프로필, 문의하기, 버전 |

여기에 더해 **같은 성격이 서로 다른 깊이에** 흩어져 있다.
테마는 계정 설정 안(3단계), 효과음은 설정 첫 화면(2단계) — 둘 다 "앱이 어떻게 보이고 들리는가"인데.

그래서 첫 화면에 **섹션 7덩어리 / 조작 10개**가 한꺼번에 쏟아진다.

---

## 2. 정한 축

> **설정 첫 화면은 "무엇을 바꿀지 고르는 목차"다. 실제 조작은 그 안에서 한다.**

이유: 조작 항목이 19개다. 한 화면에 다 놓으면 지금처럼 쏟아지고, 그렇다고 더 잘게 쪼개면
깊이만 깊어진다. **첫 화면을 목차로 만들고 깊이는 2단계로 고정**하는 게 이 규모에 맞다.

목차는 **바꾸는 대상**으로 나눈다:

1. **학습** — 무엇을 어떻게 공부할지
2. **앱** — 앱이 어떻게 행동하고 보이는지 (알림 · 화면 · 소리)
3. **리워드** — 내 캐시와 관련된 것
4. **지원 / 계정** — 문의, 계정 자체

## 3. 바뀐 구조

### 3-1. 설정 (첫 화면)

```
┌──────────────────────────────────────────────┐
│  ← 설정                                       │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │ (아바타)  엘리오                    ›  │  │ ← 탭하면 계정 설정
│  │           example@gmail.com   [Google] │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  학습                                         │
│  · 학습 트랙            한자 단어 · N3    ›   │
│  · 잠금화면 학습        켜짐              ›   │
│                                              │
│  앱                                           │
│  · 알림                                  ›   │
│  · 화면 · 소리          다크              ›   │
│                                              │
│  리워드                                       │
│  · 캐시 내역                             ›   │
│  · 기프티콘 보관함                        ›   │
│  · 친구 초대                             ›   │
│                                              │
│  지원                                         │
│  · 문의하기                              ●   │
│                                              │
│                  v0.0.1                      │
└──────────────────────────────────────────────┘
```

**섹션 4개 / 행 8개 + 프로필.** (지금은 섹션 7덩어리 / 조작 10개)

바뀐 점:
- **프로필 블록이 계정 설정 진입점이 된다.** 지금은 아무 데도 안 가는 장식이다.
  이러면 "계정" 섹션 한 줄이 통째로 사라진다.
- **학습 트랙이 인라인 편집 블록 → 한 줄 행**으로. 현재 값(`한자 단어 · N3`)을 오른쪽에 보여준다.
- **"알림 보기"를 뺀다.** 홈 헤더 종(미읽음 뱃지까지 있음)으로 이미 확실히 도달한다.
  설정 안에서 *보기*와 *설정*이 섞여 있던 문제도 같이 사라진다.
- **테마와 효과음을 "화면 · 소리" 하나로 합친다.** 둘 다 "앱이 어떻게 보이고 들리는가"다.
- **잠금화면 설정이 "계정"에서 "학습"으로.** 잠금화면 학습은 학습 기능이지 계정이 아니다.
- **친구 초대가 계정 설정에서 "리워드"로.** 캐시가 걸린 기능이다.

### 3-2. 2단계 화면들

| 화면 | 내용 | 비고 |
|---|---|---|
| **학습 설정** (신규) | `StudySelector` 4트랙 + 가나 토글 + "이 설정으로 학습하기" | 지금 설정에 인라인으로 박힌 블록을 그대로 옮긴다 |
| **잠금화면 설정** (기존) | 화면 켤 때 퀴즈 띄우기 (토글) · 잠금화면 디자인 → `LockTheme` | 그대로 |
| **알림 설정** (신규) | 푸시 알림 · 학습 리마인더 · 마케팅·이벤트 알림 | "알림 보기" 제외 |
| **화면 · 소리** (신규) | 테마 모드(시스템/라이트/다크) · 정답·오답 효과음 | 테마가 계정 설정에서 나온다 |
| **친구 초대** (신규) | `ReferralSection` 내용 + 코드 입력 | `ReferralRedeem`을 흡수할지는 §5 참고 |
| **계정 설정** (기존, 축소) | 계정 연결(게스트만) · 약관·정책 2 · 회원 탈퇴 | 친구 초대·테마가 빠져 계정만 남는다 |
| **캐시 내역 / 기프티콘 보관함** (기존) | 그대로 | 이동만 |

### 3-3. 깊이

```
전:  홈 → 설정 → 잠금화면 설정 → 잠금화면 디자인      (4단계)
후:  홈 → 설정 → 잠금화면 설정 → 잠금화면 디자인      (4단계, 그대로)
     그 외 전부 3단계 이하
```

⚠️ 잠금화면 디자인만 4단계로 남는다. 꾸미기는 자주 가는 곳이 아니라 그대로 뒀다.

## 5. 결정이 필요한 것 세 가지

### (1) 홈 배너 목적지 — ✅ 반영됨
홈 배너 "친구 초대하고 캐시 받기"가 지금 `AccountSettings`로 간다. 친구 초대가 거기서 빠지면
**배너가 엉뚱한 데로 떨어진다.** 홈 탭 재배치는 나중이지만 이 **한 줄은 같이 고쳐야** 기능이 안 깨진다.
→ `screen: 'AccountSettings'` → `'Referral'` **(적용 완료)**

### (2) `ReferralRedeem` 흡수 — ✅ 사실상 통합
지금은 *내 코드 보기*(계정 설정 안 블록)와 *친구 코드 입력*(`ReferralRedeem` 별도 화면)이 나뉘어 있다.
새 **친구 초대** 화면 하나로 합치면 화면이 하나 준다. 다만 코드 입력은 평생 1회라 별도 화면인 게
덜 헷갈릴 수도 있다.
→ **결과: 새 `Referral` 화면이 `ReferralSection`을 그대로 담는다.** 한 화면에서 코드 칩·공유·입력 진입이 다 보이고, 코드 입력만 한 단계 더 들어간다(평생 1회라 별도 화면이 안전).

### (3) 새 화면 4개 — ✅ 그대로 진행
학습 설정 / 알림 설정 / 화면·소리 / 친구 초대. 화면 수는 늘고 첫 화면은 단순해진다.
→ 조작 19개를 한 화면에 두는 게 문제였다. 목차가 짧아야 안 어지럽다.
