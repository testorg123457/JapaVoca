# JapaVoca — 프로젝트 현황 브리핑 (새 세션 Claude용)

> 이 문서는 **현재 구현 상태**를 빠르게 파악하기 위한 것이다. 새 세션은 이 파일을 가장 먼저 읽는다.
> 작업 규칙은 루트 [`CLAUDE.md`](../CLAUDE.md), 디자인 규칙은 [`디자인-시스템-원칙.md`](디자인-시스템-원칙.md), 실행 방법은 아래 §8.

## 1. 한 줄 요약

일본어(단어·한자·가나) 학습 + 캐시 리워드 안드로이드 앱. **퀴즈 정답 → 캐시상자 획득 → (광고 보고) 개봉 → 캐시 적립 → 기프티콘 교환(광고)** 이 핵심 루프. 수익 모델은 캐시워크형(AdMob 보상형 광고). 캐시는 **자산**이라 정합성(원장+잔액 트랜잭션)이 최우선 원칙.

- 서비스명: 일본어 한자 보카 / JapaVoca / 패키지 `com.japavoca.app`
- 1차 플랫폼: **Android 우선** (iOS 3차)

## 2. 모노레포 구조 & 스택

```
JapaVoca/
├── apps/
│   ├── mobile/   # React Native 0.86 (TS, New Architecture). android/ 에 네이티브(Kotlin)
│   └── server/   # Django 6 + DRF (자체 .venv), Supabase Postgres
└── docs/
```
- JS workspace 도구(Nx/Turbo/yarn workspaces) **안 씀**. mobile/server는 같은 레포의 독립 폴더.
- 백엔드는 Python venv로 독립.

| 레이어 | 채택 |
|---|---|
| 클라이언트 | React Native 0.86.0 (TS), New Architecture(Fabric/Bridgeless), Hermes |
| UI | **NativeWind(Tailwind) + 자체 토큰** (⚠️ gluestack-ui는 제거됨) |
| 상태/데이터 | React Query(서버 상태) + React Context(auth) + MMKV(토큰·설정 영속) |
| 애니메이션 | reanimated(+worklets), gesture-handler, lottie |
| 광고 | react-native-google-mobile-ads (AdMob 보상형) |
| 인증 | 구글(@react-native-google-signin) + **카카오**(@react-native-seoul/kakao-login) + **게스트** + JWT |

| DB | **Supabase Postgres 전용**. `.env`의 `DATABASE_URL` 하나로만 지정(필수, 없으면 부팅 실패). 로컬 DB 폴백 없음(레포의 `db.sqlite3`는 미사용 잔재). 테이블명은 `tbl_<app>_<model>` 규칙 |

## 3. 백엔드 아키텍처 (apps/server)

루트 라우팅(`config/urls.py`): `/api/auth/` `/api/quiz/` `/api/rewards/` `/api/exchange/` `/api/notifications/` `/api/support/` `/api/content/`

### 앱별 책임
| 앱 | 책임 | 주요 모델 |
|---|---|---|
| `accounts` | 구글·카카오·게스트 로그인·JWT 발급, 프로필, 약관동의 | `User`, `ConsentAgreement` |
| `content` | 학습 콘텐츠 + 한자 구성 트리 API | `Kanji`, `Word`, `WordMeaning`, `Kana`, `WordExample`, `KanaExample` |
| `learning` | 퀴즈 세트 출제(SRS+오답생성)·채점(SM-2)·오프라인 동기화·북마크 | `SrsState`, `QuizLog`, `QuizSet`, `QuizSetItem`, `Bookmark` |
| `rewards` | 캐시(지갑/원장)·상자·출석(달력)·데일리 | `Wallet`, `Ledger`, `CashBox`, `Attendance`, `Daily` |
| `exchange` | 기프티콘 교환·보관함·광고 SSV 검증 | `GiftExchange`, `AdRewardLog` |
| `notifications` | 인앱 알림 + 푸시 토큰 | `Notification`, `PushToken` |
| `support` | 문의하기(DB 방식) | `Inquiry` |

### 캐시 정합성 핵심 (⚠️ 절대 원칙 — CLAUDE.md)
- 모든 캐시 변동 = **Wallet 잔액 갱신 + Ledger(append-only) 기록을 하나의 `@transaction.atomic`**.
- `wallet.balance == (ledger earn합 − use합)` 항상 일치.
- 차감은 행 잠금(`_lock_wallet`) + 조건부로 음수/이중차감 방지. `Ledger`는 수정·삭제 금지.
- 금액은 전부 정수 캐시(BigInteger), 소수점 없음.
- `rewards.services`: `earn()`, `use()`, `open_cash_box()`, `check_in()`, `get_today_*()`.

### SRS / 채점 (`learning.services`)
- 출제: SRS 기한 도래 항목 우선 → 없으면 미학습 신규(가능하면 유저 급수). 오답은 같은 종류 다른 항목에서 추출.
- 문제마다 **서명된 question_token** 발급 → 채점 시 위조/만료 검증.
- 채점: 간이 **SM-2**(ease/interval/repetitions/due_at) 갱신, 정답 시 상자 생성(일일 상한 체크).
- **학습 트랙 4종**: `kanji`(한자) / `kanji_word`(한자단어) / `kana_word`(가나단어) / `kana`(가나글자).
- 가나 트랙: `Kana` 모델(hira/kata × 청음·탁음·요음), 글자→로마자 방향 고정(로마자→글자는 じ·ぢ 동음 모호성 때문).
- 보관: `QuizLog`는 **탈퇴 후 1년 보관**(부정 이용 방지, 삭제 배치 미구현). `QuizSet/QuizSetItem`은 7일 보관 후 삭제 배치.
- 상품 카탈로그: `exchange/products.py` 코드 상수 3종(아메리카노/편의점 5천·1만원권). 환율 `CASH_PER_KRW=2.23`.

    ├── Bookmarks     ← 북마크 목록
    ├── Exchange / ExchangeHistory        ← 기프티콘 교환·교환내역

(스플래시는 `react-native-bootsplash` 네이티브 스플래시 + `SplashScreen` 라우트 조합)

**온보딩 게이트** (`navigation/gateStatus.ts`): `computeGateStatus()` 순수 함수로 단계 결정.
`consentLoading → terms → permissions → studyNeeded → ready`

### API 레이어 (`api/`)
- `client.ts`: 공용 axios. access 토큰 자동 주입, **401 → refresh 1회 재시도**, refresh 실패 시 `forceSignOut()`.
- `queryClient.ts`: 캐시 레벨 onError에서 **네트워크 끊김만** 잡아 전역 Toast(공용 메시지). 네트워크 오류만 2회 재시도, 4xx/5xx는 재시도 안 함(캐시 이중 실행 방지).
- `hooks.ts` / `quiz.ts` / `boxes.ts` / `exchange.ts` / `notifications.ts`: React Query 훅 모음.

### 앱 전역 디자인 (`theme/tokens.ts` 단일 소스 + NativeWind)
- 색·간격·라운드·그림자·타이포를 토큰에서만 정의(하드코딩 금지). **라운드는 단단하게**(버튼 12/카드 16/시트 24 — 둥글둥글·직각 둘 다 지양), 포인트 컬러 절제, 폰트 Pretendard.
- 라이트/다크 2세트 semantic. 다크는 **쿨 잉크** 톤(웜 브라운 폐기).
- 공용 컴포넌트 `components/`: `AppText`/`Button`/`Card`/`CashBadge`/`Icon`(SVG 36종)/`Tag`/`SectionHeader`/`ProgressBar`/`Gradient`/`PressableScale`/`StudySelector` + `AppHeader`/`ConfirmSheet`/`ListRow`/`ListSection`(+inset)/`ToggleRow`/`Toast`.
- `StyleGuideScreen`으로 전체 컴포넌트 확인(설정 → 디자인 시스템, DEBUG 진입점).

### 퀴즈 전용 테마 시스템 (`theme/quiz/`) ⚠️ 앱 전역 토큰과 별개
- 퀴즈(잠금화면)는 **자체 테마 계약**을 가진다: `contract.ts`(QuizTheme = colors + shape) → `themes/`에 6종(**classic**=인디고 다크(기본)·forest(연두)·olive·dracula·sage·pink) → 사용자가 `LockThemeScreen`에서 선택, `store/quizTheme`에 저장. classic/forest/olive/dracula/sage는 단색 다크, pink만 이미지 배경 라이트. `sage`는 배경-면 대비가 약해 `choiceOutline`으로 선택지 테두리를 켬.
- `QuizThemeProvider`가 마운트 시 테마 고정, `useQuizTheme()`로 소비. `ChoiceCard`·`AudioButton`·`QuizBackground`가 이 테마만 참조(앱 전역 `useThemeColors`와 다름).
- **현재 기본(classic) = 인디고 다크**: bg `#16181F`, 면 `#2A3040`, brand `#7C9EFF`, 정답 `#46D08A`, 오답 `#FF6B6B`. 배경은 단색(그라데이션 없음).
- shape: `choiceStyle`(fill/outline/soft), `choiceLayout`(grid2x2), radius, `needsTextScrim`(사진 배경 테마용).
- ⚠️ `choiceCardStyle`은 순수함수 — 테스트 있음(`__tests__/quizTheme.choiceCard.test.ts`). 색 바꾸면 테스트도 갱신.

## 6. 핵심 루프 현 구현 정리

온보딩(✅) → 로그인(✅) → 홈(✅) → 퀴즈 정답(✅) → 상자 생성(서버 ✅) → 상자 개봉+광고(🟡) → 캐시 적립(서버 earn ✅) → 지갑(🟡) → 기프티콘 교환+광고(서버 로직 ✅ / 발급사 Mock) → SSV 검증(✅).

**서버 비즈니스 로직은 대부분 구현.** 프론트는 로그인·온보딩·홈·퀴즈까지 검증됨. 상자 개봉 이후 화면(개봉/지갑/교환/보관함)은 코드만 있고 실제 플로우 검증 전.

## 7. 주요 변경 이력 & 미구현

**구조적으로 굳은 결정**
- **gluestack-ui 제거** → NativeWind + 자체 컴포넌트.
- **게스트 로그인**: UUID 즉시 진입, 추후 소셜 연결(`/api/auth/link/`).
- **BottomTab 제거** → 홈 단일 스크롤. 지갑·설정은 홈/설정에서 진입.
- **온보딩 게이트**: `computeGateStatus()` 기반 약관·권한·학습선택 강제.
- **가나 학습 트랙 추가**(4번째): `Kana` 모델 + SRS + 글자→로마자 퀴즈.
- **잠금화면 학습**: 배터리 최적화 권한 필수, 네이티브 모듈(`BatteryOptimizationModule.kt`).
- **DB Supabase 전용**: 로컬 폴백 제거, `DATABASE_URL` 필수.
- **퀴즈 세트 시스템**: `QuizSet/QuizSetItem` + `/set/`·`/sync/`·`/abandon/`.
- **문의하기 DB 방식**: `support` 앱(구 Gmail Alert 대체).

## 8. 실행 방법

- **DB**: Supabase Postgres 전용. `.env`에 `DATABASE_URL` 필수(없으면 부팅 실패). 로컬 폴백 없음.
- **백엔드**: `cd apps/server && source .venv/bin/activate && python manage.py runserver 0.0.0.0:8001`
- **에뮬레이터**: `API_BASE_URL=http://10.0.2.2:8001` (`.env`)
- **실기기(USB)**: `adb reverse tcp:8001 tcp:8001` + Metro는 `tcp:8081`. (⚠️ USB 재연결 시 reverse 리셋됨 — 재설정 필요)
- **모바일**: `cd apps/mobile && npm install && npx react-native start` + `npx react-native run-android` (첫 빌드 오래 걸림).
- **마이그레이션**: Supabase에 스키마 적용 완료. 콘텐츠(한자·단어·가나) 시드는 직접 입력.
- 구글 키 없으면 **"개발용 로그인(DEBUG)"** 또는 **게스트 로그인**.

## 10. 디자인 시스템 ⚠️ (UI 작업 전 필독)

> 실물은 `StyleGuideScreen`(설정 → 디자인 시스템, DEBUG). 규칙 상세는 [`디자인-시스템-원칙.md`](디자인-시스템-원칙.md).
> 퀴즈 화면은 앱 전역 토큰이 아니라 **`theme/quiz/` 별도 시스템**을 쓴다(§4 참조).

### 핵심 원칙
1. **이모지를 기능 아이콘으로 쓰지 않는다.** 내비/상태/구조엔 `Icon`(SVG)만. 이모지는 보상 연출에만.
2. **색은 기능적으로만.** 민트=주 액션/활성, 옐로=캐시/리워드, 회색=중립, danger=경고. 장식 색 금지.
3. **위계는 크기 + 굵기로.** Bold(hero/title) → SemiBold(heading/label) → Regular(body/caption).
4. **여백이 숨쉬게.** 섹션 간 `gap-2xl`(20)+, 카드 패딩 `p-xl`(16).
5. **단단한 라운드.** 둥글둥글·완전 직각 둘 다 지양(사용자 취향). 부드러움은 그림자·여백·위계로.
6. **색 인라인은 `useThemeColors()`, className은 semantic 토큰**(`bg-bg-primary`/`text-text-secondary`/`bg-brand`…).

### 토큰 (`theme/tokens.ts`)
- **폰트**: Pretendard 4종. ⚠️ 폰트는 네이티브 에셋 → **`run-android` 재빌드해야 적용**.
- **typography**: `hero 34 / display 26 / title 19 / heading 16 / subheading 15 / body 14 / label 13 / caption 12 / micro 11`.
- **radius**: sm 8 / md 12(버튼) / lg 16(카드) / xl 20(큰카드) / 2xl 24(시트) / full.
- **gradients**: `brand` `[mint300, mint600]` / `brandSoft` `[mint50, mint100]` — hero 카드용(절제 사용).

### 공용 컴포넌트 (`components/`)
| 컴포넌트 | 용도 |

| `AppText` | variant(타이포). 기본색 text-primary |

| `Card` | variant(default/elevated/flat/brand) · `onPress` |
| `Icon` | SVG 아이콘 36종 (coffee/store/alert 등 포함) |

| `CashBadge` | SVG 코인 + 금액 pill |
