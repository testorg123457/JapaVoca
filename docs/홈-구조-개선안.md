# 홈 구조 — 결론: 거의 안 건드린다

> 현재 상태는 [`화면-구조-현황.md`](화면-구조-현황.md), 설정 쪽은 [`설정-구조-개선안.md`](설정-구조-개선안.md).
> 작성 2026-08-04.

---

## 1. 결론

**홈은 지금 구조 그대로 둔다.** 반드시 고쳐야 하는 건 **배너 목적지 한 줄**뿐이고,
그것도 설정 개편 때 같이 처리하면 된다.

처음엔 하단 리스트를 학습/캐시 두 그룹으로 나누려 했는데, **기프티콘 보관함이 홈에 올라오지
않기로 하면서 그 전제가 사라졌다**(보관함은 자주 쓰는 기능이 아니라 설정에 둔다).
보관함이 없으면 "캐시" 그룹은 `기프티콘 교환` **한 줄뿐**이다. 1행짜리 그룹을 만들자고
리스트를 쪼개는 건 정리가 아니라 부스러기다.

---

## 2. 반드시 고쳐야 하는 것 (1개)

### 배너 "친구 초대" 목적지
지금 `AccountSettings`로 간다. 설정 개편에서 친구 초대가 계정 설정 밖으로 나가므로
**목적지를 새 `Referral` 화면으로 바꿔야 한다.** 안 고치면 배너가 엉뚱한 데로 떨어진다.

→ `HomeBannerCarousel`의 `screen: 'AccountSettings'` → `'Referral'` **한 줄.**
→ **설정 작업에 포함**한다(`설정-구조-개선안.md` §5-1).

---

## 3. 해도 되고 안 해도 되는 것 (선택)

### (a) 리스트 순서만 바꾸기
현재 `히라가나/가타카나 · 기프티콘 교환 · 일본어 번역 · 북마크` — 캐시(교환)가 학습 항목 사이에 껴 있다.
`히라가나/가타카나 · 북마크 · 일본어 번역 · 기프티콘 교환`으로 **성격순 정렬만** 하면
그룹을 쪼개지 않고도 읽기가 나아진다. 1줄 작업.

### (b) 배너 콘텐츠 교체
현재 3장 중 2장(`일본어 번역`·`기프티콘 교환`)이 바로 위 리스트와 중복이다.
다만 **지금 들어있는 건 전부 자리표시용**이고 나중에 다른 기능·광고로 교체될 예정이라,
급히 바꿀 이유는 없다. **아래 슬롯 규칙만 지키면 된다.**

---

## 4. 배너 슬롯 규칙 (앞으로 콘텐츠 넣을 때)

> **배너는 "리스트에 없는 것"을 알리는 자리다.**

리스트에 이미 있는 기능을 배너로 다시 광고하면 바로 위 행을 4.5초마다 반복 노출하는 셈이라
배너가 정보가 아니라 장식이 된다.

| 담을 것 | 담지 않을 것 |
|---|---|
| 이벤트·공지 / 신규 기능 / 외부 광고 / 캐시 유입 장치(초대) / **묻혀 있는 기능** | 홈 리스트·헤더에 이미 진입점이 있는 것 |

**"묻혀 있는 기능"의 좋은 후보: 잠금화면 학습.** 앱의 2차 핵심 기능인데 지금
설정 → 계정 → 잠금화면 설정까지 **3단계**를 파야 켤 수 있다(개편 후엔 설정 → 학습 → 잠금화면, 2단계).

### 나중에 광고가 들어올 때 미리 정해둘 것
- **자사 프로모션과 외부 광고를 같은 캐러셀에 섞으면** 기능인지 광고인지 구분이 안 된다
  → 광고 카드엔 **"광고" 라벨**(표시 의무와도 맞물린다)
- 위치는 **하단 유지**. 주액션(퀴즈)과 리스트 사이에 끼우면 학습 진입을 방해한다
- ⚠️ **1장만 남으면 자동순환·점 인디케이터를 꺼야 한다.** 넘길 게 없는데 점이 있으면 고장으로 보인다

## 5. 확인하다가 나온 문서 오류 (정정 완료)

| 문서가 말하던 것 | 실제 | 처리 |
|---|---|---|
| 홈 진행 문구는 하드코딩 | `useDailyToday()` 연동돼 있음 | `프로잭트-현황.md` 정정 |
| 홈 하단에 **AdMob 배너** | 자사 프로모션 캐러셀(`HomeBannerCarousel`). **앱 전체에 `BannerAd` 사용처가 없다** — AdMob은 보상형만 쓴다 | `프로잭트-현황.md` 정정 |

⚠️ 수익 모델이 광고인데 **디스플레이 광고가 아직 한 곳도 붙어 있지 않다.** IA 문제는 아니지만
수익화 착수 시 이 배너 슬롯이 첫 후보다(§4 라벨 규칙 참고).

## 6. 안 건드리는 것

- 헤더 (캐시 잔액 · 알림 종 · 설정)
- 진행 문구 — `useDailyToday()` 연동 확인됨
- 퀴즈 CTA · 상자 카드 — 주액션과 리워드. 상자 카드 뒤 스택 레이어는 홈의 시그니처다
- 하단 리스트 그룹 — 쪼개지 않는다(§1)
- 배너 캐러셀 구현 — 자동순환·reduce motion 처리 다 돼 있다
- ⚠️ **홈 상단 기각 이력**: ① 민트 그라데이션 히어로 + 겹침 시트 ② 민트 솔리드 헤더 + 은행 스트립.
  **그라데이션 X · 겹침 시트 X · 상단 민트 블록 X.** 화이트 톱 기조 유지.
