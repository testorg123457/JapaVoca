# 피드백 체크리스트

실기기 사용 중 발견한 이슈/개선 요청 모음.

- [ ] 이미 풀었던 문제, 앱 껐다가 다시 들어가면 또 나옴
- [ ] "모자랄 결(缺)" 한자에 구성자로 "하품 흠(欠)"이 있는데, 구성 자세히 보기 들어가면 없음
- [x] 촬영 페이지 디자인 변경
- [x] 촬영 분석 안 됨 — 원인은 코드 아님. 서버에 `GOOGLE_API_KEY` 미설정(서버 `.env` 부재)이 원인. 실제 API 확인 결과 `gemini-2.5-flash`/`gemini-2.0-flash`·이미지 호출 모두 정상 동작. **`.env` 생성 완료 → 배포 시 서버에도 `GOOGLE_API_KEY` 반영됐는지만 확인**하면 됨 (코드 변경 없음)
- [ ] 문제를 10개 다 풀었는데 갑자기 이전에 풀었던 문제로 순간이동함
- [ ] 한자 단어에서 "위 상"이 나왔는데 4지선다가 그냥 "상"임
- [ ] 한자 단어에서, 무슨 한자인지가 나와야 하는데 안 나오고 그 한자의 구성자만 나옴
- [ ] "길 도(道)"가 "미치"도 되는 거 아님? 그냥 듣기 했는데 "도우" 하고 끝, "물고기(魚)"도 "으오" 이러고 끝남
- [ ] 문제에 구성자만 나옴 (무슨 한자인지 표시 안 됨)
- [ ] 단어면 발음(히라가나/가타카나)도 보여줘야지
- [ ] 상자 터치 안 됨. 위쪽 눌러야 열림 → 터치 범위를 크게 늘려
- [ ] 상자 위치 좀 아래로 내려
- [ ] "벤쿄우(勉強)"가 "열심히 일을 함"으로 되어 있음 → 이건 "공부"잖아
- [ ] 정답 눌렀을 때 반응이 즉각적이지 않음
- [ ] 정답 맞췄을 때 / 틀렸을 때 소리가 났으면 좋겠음
- [ ] 한자 단어 두 글자랑 세 글자랑 크기 차이가 엄청남
- [ ] 오답노트 보고 있는데 새 세트가 만들어져서 오답노트 꺼짐 (아직 다 안 봤는데)
- [ ] 상자 눌렀는데 갑자기 화면 멈춤. 나갔다 들어와야 열림
- [ ] 캐시 내역 디자인
- [ ] 네트워크 끊겼으면 몇 초 재시도해봐야 하는데 그냥 바로 "연결 안 됨" 뜸
- [ ] 뒤로가기 눌렀는데 상자페이지 가짐
- [ ] 알림 페이지 디자인
- [ ] 배너 디자인
- [ ] 출석 달력 디자인
