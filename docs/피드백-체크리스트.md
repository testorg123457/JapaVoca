# 피드백 체크리스트

실기기 사용 중 발견한 이슈/개선 요청 모음. 원문 표현 그대로 두고 성격별로만 묶었다.

> 처리 순서 추천: **A → C → E → B → D → F**.
> A와 C는 원인이 겹칠 가능성이 높아(세트 커서 / 렌더 순서) 한 덩어리로 파는 게 효율적.

## A. 출제 로직 — 가장 심각

학습 신뢰가 깨지는 영역. `docs/프로잭트-현황.md` §7의 "오래된 퀴즈 세트 재개 미해결"과 직결돼 보임.

- [ ] 이미 풀었던 문제, 앱 껐다가 다시 들어가면 또 나옴
- [ ] 문제를 10개 다 풀었는데 갑자기 이전에 풀었던 문제로 순간이동함
      ↳ 위 항목과 같은 커서/세트 문제 계열일 가능성
- [ ] 한자 단어에서, 무슨 한자인지가 나와야 하는데 안 나오고 그 한자의 구성자만 나옴 <- 이거 이미 한거 아닌가 ? 확인 필요

## B. 콘텐츠 데이터

코드가 아니라 시드 데이터 쪽. 별도 트랙으로 진행 가능.

- [ ] "모자랄 결(缺)" 한자에 구성자로 "하품 흠(欠)"이 있는데, 구성 자세히 보기 들어가면 없음
- [ ] "길 도(道)"가 "미치"도 되는 거 아님? 그냥 듣기 했는데 "도우" 하고 끝, "물고기(魚)"도 "으오" 이러고 끝남
      ↳ 훈독 누락(음독만 있음)
- [ ] 단어면 발음(히라가나/가타카나)도 보여줘야지
      ↳ 데이터 + UI 양쪽일 수 있음

## C. 상자 / 캐시 루프

돈 루프가 막히는 영역이라 A 다음 우선순위.

- [ ] 상자 터치 안 됨. 위쪽 눌러야 열림 → 터치 범위를 크게 늘려
      ↳ 현황 문서 §5의 zIndex/렌더 순서 이슈와 연관
- [ ] 상자 눌렀는데 갑자기 화면 멈춤. 나갔다 들어와야 열림
- [ ] 상자 위치 좀 아래로 내려
- [ ] 뒤로가기 눌렀는데 상자페이지 가짐

## D. 퀴즈 반응성·피드백

- [ ] 정답 눌렀을 때 반응이 즉각적이지 않음
      ↳ 서버 채점 왕복 대기로 보임. 낙관적 UI 필요
- [ ] 정답 맞췄을 때 / 틀렸을 때 소리가 났으면 좋겠음
- [ ] 한자 단어 두 글자랑 세 글자랑 크기 차이가 엄청남

## E. 네트워크
