# 피드백 체크리스트

실기기 사용 중 발견한 이슈/개선 요청 모음. 원문 표현 그대로 두고 성격별로만 묶었다.

> 처리 순서 추천: **A → C → E → B → D → F**.
> A와 C는 원인이 겹칠 가능성이 높아(세트 커서 / 렌더 순서) 한 덩어리로 파는 게 효율적.

---

## A. 출제 로직 — 가장 심각

학습 신뢰가 깨지는 영역. (예전에 의심했던 "오래된 세트 재개"는 서버에 이미 방어가 있었다 — `_last_reset_cutoff()` + `SET_RESET_HOUR=3`으로 새벽 3시 이전 세트는 폐기한다.)

- [x] 이미 풀었던 문제, 앱 껐다가 다시 들어가면 또 나옴
      ↳ 커서를 '다음' 버튼이 아니라 제출 즉시 올리도록 수정 (`9d7b20e`, 회귀 테스트 있음).
- [ ] 문제를 10개 다 풀었는데 갑자기 이전에 풀었던 문제로 순간이동함
      ↳ 아래 동기화 항목과 같은 원인으로 추정(앱이 서버에 진행상황을 묻는 시점이 세트 끝뿐). 별도 결함은 못 찾음 — 실기기 재현으로 판정
- [x] 오프라인에서 푼 답을 올리기 전에 서버 세트를 먼저 받아와서, 방금 푼 세트를 처음부터 다시 풀게 됨
      ↳ 동기화를 세트 조회 앞으로 + 보낸 답만 큐에서 제거 (`9c597c7`).
- [x] 오답노트 보고 있는데 새 세트가 만들어져서 오답노트 꺼짐 (아직 다 안 봤는데)
      ↳ 새 세트가 잡히면 복습을 강제로 닫던 effect 제거. 이제 사용자가 닫아야만 닫히고, 새 세트는 뒤에서 대기한다 (`577e65d`)
- [x] 한자 단어에서, 무슨 한자인지가 나와야 하는데 안 나오고 그 한자의 구성자만 나옴
      ↳ 구성 자세히 보기가 구성자부터 그리고 본체는 visited로 배제했었다. 본체를 트리 뿌리(depth 0)로 세워 뜻·음훈독이 나오게 함.

## B. 콘텐츠 데이터

코드가 아니라 시드 데이터 쪽. 별도 트랙으로 진행 가능.

- [ ] "모자랄 결(缺)" 한자에 구성자로 "하품 흠(欠)"이 있는데, 구성 자세히 보기 들어가면 없음
- [ ] "길 도(道)"가 "미치"도 되는 거 아님? 그냥 듣기 했는데 "도우" 하고 끝, "물고기(魚)"도 "으오" 이러고 끝남
      ↳ 훈독 누락(음독만 있음)
- [ ] 단어면 발음(히라가나/가타카나)도 보여줘야지
      ↳ 데이터 + UI 양쪽일 수 있음

## C. 상자 / 캐시 루프

돈 루프가 막히는 영역이라 A 다음 우선순위.

- [x] 상자 터치 안 됨. 위쪽 눌러야 열림 → 터치 범위를 크게 늘려
      ↳ 탭 영역을 그림과 분리해 아래로 크게(면적 약 2.4배) 넓히고, 안드로이드가 부모 밖 터치를 안 주므로 무대 높이도 함께 키움(음수 marginBottom으로 상쇄). Lottie는 pointerEvents 제거해 판정에서 뺌.
- [x] 상자 눌렀는데 갑자기 화면 멈춤. 나갔다 들어와야 열림
      ↳ 원인 2개. ① 개봉 요청에 타임아웃이 없어 응답이 안 오면 phase가 'opening'에 갇힘 → 15초 상한. ② mountedRef를 마운트 시 true로 안 되돌려 Fast Refresh 후 응답을 무시함 → 수정. 광고 콜백이 안 오는 경우는 미해결(아래 메모).
- [x] 상자 위치 좀 아래로 내려
      ↳ transform translateY 6px(레이아웃이 아니라 transform이라 탭 영역도 같이 내려감).
- [x] 뒤로가기 눌렀는데 상자페이지 가짐
      ↳ 잠금화면 퀴즈의 상자 뱃지에 연타 방지가 없어 개봉 화면이 스택에 두 번 쌓였다. 홈과 같은 방식(navLock + 화면 복귀 시 해제)으로 막음

## D. 퀴즈 반응성·피드백

- [ ] 정답 눌렀을 때 반응이 즉각적이지 않음
      ↳ 서버 채점 왕복 대기로 보임. 낙관적 UI 필요
- [x] 정답 맞췄을 때 / 틀렸을 때 소리가 났으면 좋겠음
      ↳ react-native-audio-api로 정답·오답 효과음. 설정에 끄기 토글 추가(기기 설정, MMKV). ⚠️ 네이티브 의존성이라 리빌드 필요.
- [x] 한자 단어 두 글자랑 세 글자랑 크기 차이가 엄청남
      ↳ 카드마다 제 글자 수로 크기를 정하던 걸 폐기. 네 선택지가 '가장 긴 것' 기준 한 크기를 공유하고, 2~4글자는 26으로 통일·계단은 2px로 완만하게.

## E. 네트워크

- [x] 네트워크 끊겼으면 몇 초 재시도해봐야 하는데 그냥 바로 "연결 안 됨" 뜸
